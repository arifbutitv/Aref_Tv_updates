# صور خلفيات واجهة ArifButi

أضف صور JPG من **Add file → Upload files**، أو افتح الصورة ثم **⋯ → Delete file** لحذفها.

استخدم أسماء إنجليزية دون مسافات مثل `bahrain-01.jpg`، ويفضل قياس 1920×1080.

يتحدث `index.json` آليًا بعد الحفظ عبر GitHub Actions؛ لا تحتاج إلى تعديل التطبيق أو إنشاء APK جديد.
